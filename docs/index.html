📱 텔레그램 알림 설정
보유 종목의 목표가 도달 또는 손절가 이탈 시 텔레그램으로 즉시 알림을 받을 수 있습니다.
봇 토큰과 채팅 ID를 입력하고 저장하면 자동으로 감지합니다.
ℹ️ 텔레그램 봇 설정 방법
① 봇 생성
텔레그램에서 @BotFather 를 검색 →
/newbot 명령어 입력 → 봇 이름/사용자명 설정
→ 발급된 토큰을 위에 입력
② 채팅 ID 확인
생성한 봇에게 아무 메시지 전송 후
브라우저에서 아래 URL 접속:
https://api.telegram.org/bot토큰/getUpdates
→ result[0].message.chat.id 값이 채팅 ID
③ 그룹 채널 (선택)
그룹/채널에 봇을 추가하면 그룹 채팅 ID 사용 가능
채널 채팅 ID는 보통 -100으로 시작
🔔 알림 발송 조건
🎯 목표가 도달
포트폴리오 보유 종목의 현재가 ≥ 목표가
🚨 손절가 이탈
포트폴리오 보유 종목의 현재가 ≤ 손절가
시세 가져오기 또는 현재가 직접 입력 시 자동 체크됩니다.
동일 조건 중복 발송 방지: 30분 쿨다운 적용
🏦 키움증권 REST API 설정
키움증권 REST API를 이용해 보유종목·관심종목의 현재가를 직접 조회합니다.
App Key / App Secret은 키움 개발자센터에서 앱 등록 후 발급받을 수 있습니다.
ℹ️ 키움 REST API 설정 방법
① 앱 등록
키움증권 개발자센터 접속 → 앱 등록
→ App Key와 App Secret 발급
② 종목코드 형식
포트폴리오·관심종목의 종목코드를
005930.KS 형식으로 입력하면
키움 API 조회 시 6자리 코드로 자동 변환됩니다.
③ 토큰 발급
저장 후 토큰 발급 버튼 클릭
→ 24시간 유효 / 만료 시 자동 재발급
